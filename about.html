Zeig deine Position, deinen Öffnungsstatus und befreundete Spaces – per iframe, ohne Registrierung.

1. Live-Vorschau — 440 px

2. Live-Vorschau — 640 px (mit Minimap)

3. Code-Snippet

<script src="https://makerspac.es/embed-loader.js" data-id="DEINE_ID" data-height="440"> </script>
<iframe src="https://makerspac.es/embed.html?id=DEINE_ID" width="100%" height="440" style="border:none;border-radius:10px;" title="Makerspace-Karte"> </iframe>

4. Parameter

Parameter Beschreibung Beispiel
id Pflicht ID deines Makerspace (sichtbar im Popup auf der Karte) id=1
friends optional IDs befreundeter Spaces, kommagetrennt friends=12,34
country optional Land-Filter country=Germany
lang optional Sprache: de, en, fr, nl, it, da, uk lang=de
